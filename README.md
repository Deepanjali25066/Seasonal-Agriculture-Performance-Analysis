# Seasonal-Agriculture-Performance-Analysis

Major Data Analytics project analyzing how agricultural performance 
(yield, profit, water usage) varies across seasons (Kharif, Rabi, Zaid) 
using a dataset of 4,000 farm records.

**Domain:** Data Science and Artificial Intelligence (VOIS AICTE Internship)
**Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn

## Files
- `Seasonal_Agriculture_Performance_Data_Analytics.ipynb` — full analysis notebook
- `seasonal_agriculture_performance_dataset.csv` — dataset
- `Major_Project_Seasonal_Agriculture_Performance_Analysis_.pdf` — project brief

## Key Findings
- Profitability declines much faster than yield across seasons
- Water efficiency, not rainfall, is the strongest driver of yield
- Zaid season shows the highest proportion of loss-making farms (64.5%)
